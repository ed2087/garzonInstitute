# Garzón Institute – Landing Page Demo

This repository contains the original **demo version** of the landing page for the Garzón Institute. It serves as the initial design foundation for the website project that introduces the mission, vision, team, and initiatives of the institute in a modern, engaging format.

---

## 🌎 Overview

The Garzón Institute is committed to scientific research, innovation, and community development, especially within Amazonian regions. This landing page was designed to reflect those values with clarity and visual appeal.

---

## 🎯 Purpose of This Demo

This version was built to establish:

- A visual direction aligned with the institute’s identity
- A working prototype for layout, navigation, and interactive features
- A platform for collecting early feedback from stakeholders

---

## 🧱 Contents

- `index.html` – Base structure of the landing page
- `rootStyles.css` – Styling including layout, typography, animations
- `landingpage.js` – JavaScript logic for interactivity and animations
- `public/img/` – Images for header, mission, quote section, and logos

---

## ✨ Key Features

- **Hero section** with animated text and particles
- **Mobile-first responsive design**, optimized for all screens
- **Team slider** with 3D tilt effect and flip cards
- **Projects carousel** and **news reveal animations**
- **Lightbox gallery** for immersive media viewing
- **Smooth scrolling navigation**
- **Multi-language toggle (visual only for now)**

---

## 🛠️ Notes

- All images are placeholder and subject to change
- This is a standalone static front-end demo; no backend integration
- Intended to be used as the design and interaction base for future enhancements
